# Student Support Chatbot

An AI chatbot built with Streamlit that helps students with academic questions and study support.

## Features
- Ask academic questions in a chat box and get instant answers
- Topic suggestions in the sidebar (Mathematics, Science, History, Literature, Programming, General Study Tips)
- Clear Chat button to start a new conversation

## How to run
1. Install the requirements: pip install -r requirements.txt
2. Run the app: streamlit run app.py (or double-click start.bat)
3. Open http://localhost:8501 in the browser (the port shown in the terminal)

## Files
- app.py : main chatbot code
- requirements.txt : required Python libraries
- start.bat : file to start the chatbot
